# TOMORI FOCUS 使い方ガイド

仕事や勉強に集中するための、シンプルなタイマーです。**25分集中 → 5分休憩** をくり返して、集中のリズムをつくります。

アプリはこちら → https://tomoricot-alt.github.io/tomori-focus-001/

登録やログインは不要です。開くだけで使えます。

---

## 1. 基本の使い方

| やりたいこと | 操作 |
| --- | --- |
| 集中を始める | 画面の緑の **「開始」** を押す |
| 一時的に止める | **「一時停止」** を押す（残り時間はそのまま保たれます） |
| 続きから再開する | **「再開」** を押す |
| 最初からやり直す | **「リセット」** を押す（25:00 または 05:00 に戻ります） |
| 休憩を先にとる | 上のタブ **「休憩 5分」** を押す |
| 集中に戻る | 上のタブ **「集中 25分」** を押す |

### 1回の流れ
1. 「開始」を押す（25:00 からカウントダウン）
2. 0になると**音（スマホ版アプリではバイブ）**でお知らせ、自動で **休憩 05:00** に切り替わる
3. 休憩で「開始」を押す → 5分たつと、自動で集中の画面に戻る

> 休憩は自動では始まりません。休む準備ができたら「開始」を押してください。

## 2. 記録について

画面の下に、記録が表示されます。

- **今日の集中回数** … 今日、25分を最後までやりきった回数
- **今日の合計時間** … その合計の時間
- **過去7日間** … 日ごとの回数・時間・棒グラフ（今日が一番上）

### 記録される条件
- 記録されるのは **25分を最後まで完了した集中** だけです。
- 途中でリセットしたり、タブを切り替えたりした分は記録されません。
- 休憩の時間は記録されません。

### データの保存場所
- 記録は **お使いの端末（ブラウザ）の中だけ** に保存されます。サーバーには送信されません。
- そのため、**端末やブラウザが違うと記録は共有されません**（パソコンとiPhoneで別々になります）。
- ブラウザの「閲覧履歴データの削除」や「サイトデータの削除」をすると、記録も消えます。
- 8日以上前の記録も保存されていますが、画面には直近7日間だけが表示されます。

## 3. iPhoneで使う

### Safariで開く
1. iPhoneの **Safari** で上のURLを開く
2. そのまま使えます

### ホーム画面に追加する（アプリのように使える）
1. Safariで開いた状態で、下の **共有ボタン（□に↑のマーク）** を押す
2. **「ホーム画面に追加」** を選ぶ
3. 右上の **「追加」** を押す

ホーム画面のアイコンから、すぐに開けるようになります。

### iPhoneで使うときの注意
- **画面を開いたまま** 使うのがおすすめです。タイマーはロック中・他のアプリを開いている間は音でお知らせできないことがあります。
- ただし、時間そのものは正確に計算されます。画面を開き直すと、正しい残り時間（または完了済みの結果）が表示されます。
- iPhoneの **マナーモード** のときは、完了音が鳴らないことがあります。

## 4. パソコンで使う

ブラウザ（Chrome・Edge・Safari など）で上のURLを開くだけです。

- タイマーが動いている間は、**ブラウザのタブの名前に残り時間** が表示されます（例：`24:10 集中 - TOMORI FOCUS`）。別のタブで作業していても、残り時間を確認できます。
- URLを「ブックマーク」に入れておくと便利です。

## 5. よくある質問

**Q. 開いたら画面が真っ白です**
A. 少し待ってから、ページを再読み込みしてください。直らない場合は、ブラウザのキャッシュを削除するか、別のブラウザで試してください。

**Q. 25分たったのに音が鳴りません**
A. 端末の音量・マナーモード、ブラウザの音声の設定を確認してください。音が鳴らなくても、画面は休憩に切り替わり、記録は残ります。

**Q. 昨日の記録が見えません**
A. 同じ端末・同じブラウザで開いているか確認してください。別のブラウザやプライベートモードでは、記録は引き継がれません。

**Q. 記録を消したい**
A. ブラウザの設定で、このサイト（`tomoricot-alt.github.io`）のサイトデータを削除してください。

**Q. 集中時間を25分以外に変えたい**
A. 現在のバージョンでは変更できません。今後のアップデートで検討中です。
